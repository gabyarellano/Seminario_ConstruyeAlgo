# ¡Construye Algo! 
## MATLAB y Simulink para proyectos de hardware

Trabajar con hardware se ha convertido en una habilidad fundamental para los estudiantes de ingeniería de hoy en día. Si aún no has tenido que programar una placa Arduino®, Raspberry Pi™ u otra tarjeta, probablemente sea solo cuestión de tiempo antes de que lo hagas.

Estas placas pueden usarse para construir todo tipo de robots y dispositivos divertidos y atractivos y ofrecen a los estudiantes una forma práctica de aplicar los conceptos aprendidos en clase.
